# NotifyFlow — Smart Routine Notification System

A full-stack **Smart Routine Notification application built with the MERN stack**, designed to help users manage daily routines through intelligent reminders, real-time notifications, adaptive scheduling, and productivity analytics.

## Features

* JWT-based authentication & authorization
* Smart routine creation with custom schedules
* Real-time notifications with sound alerts
* Multiple alarm sounds with volume control
* Complete, snooze, and dismiss notifications
* Adaptive scheduling based on user response
* Productivity and notification analytics
* Routine priority and category management
* Keyboard shortcuts for quick actions
* Emergency stop for all sounds
* Responsive glassmorphism UI
* Real-time communication using WebSockets

## Tech Stack

**Frontend**

* React.js
* React Router
* Context API
* Axios
* Socket.io Client
* Chart.js
* JavaScript / CSS

**Backend**

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt
* Socket.io
* Node-cron

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd ../frontend
npm install
npm start
```
